# TalkUp 英语口语学习

> 让每一个成年人把英语说出口。

## 项目结构

```
talkup/
├── web/       # 前端网页（React/Babel 单文件）
├── server/    # 后端 Node.js API
└── docs/      # 项目文档
```

## 技术栈

- **前端**: React + Babel（单文件部署）
- **后端**: Node.js + Express
- **数据库**: SQLite
- **部署**: Nginx

## 开发规范

详见 [CODE_GUIDE.md](CODE_GUIDE.md)

## 快速开始

### 前端开发
```bash
# 直接在浏览器打开
open web/talkup.html
```

### 后端部署
```bash
cd server
npm install
node index.js
```
